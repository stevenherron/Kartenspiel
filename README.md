# Kartenmappe

Magic-Karten per Handykamera scannen, Sammlung und Wert verfolgen. Reine statische Web-App, kein Build nötig.

## Veröffentlichen (eine Möglichkeit reicht)
- **Netlify Drop**: app.netlify.com/drop öffnen und den entpackten Ordner hineinziehen.
- **Vercel**: Ordner entpacken, `vercel` im Ordner ausführen (Framework: „Other“).
- **GitHub Pages / Cloudflare Pages**: Ordnerinhalt in ein Repository legen und Pages aktivieren.

Die Seite muss über **https** laufen, sonst erlaubt der Browser keine Kamera.

## Nutzung
1. Tab „Sets“: deine Editionen suchen und hinzufügen (z. B. Kaladesh).
2. Tab „Scannen“: Set antippen, Karte in den Rahmen halten, „Karte lesen“.
3. Tab „Sammlung“: Karten, Gesamtwert und Preisentwicklung.
Zum Installieren auf dem Handy: im Browser „Zum Startbildschirm hinzufügen“.
